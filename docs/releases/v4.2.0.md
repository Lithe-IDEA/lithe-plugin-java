# Java 4.2.0

## 中文

为自动准备的完整 JDK 25 增加国内多镜像源自动择优与故障切换，显著提升国内环境安装 Java 插件时的下载速度。

### 新功能

- **JDK 25 多镜像源自动切换（`managedRuntimes` 1）**：将 macOS / Linux / Windows x64 的服务专用 JDK 25 切换为 Eclipse Temurin `25.0.5+8`，并同时声明官方源、南京大学镜像站（NJU）与清华大学镜像站（TUNA），配合宿主自动测速择优与失败/低速回退，仍严格校验固定 SHA-256。

### 兼容性

- **需要声明 `managedRuntimes` 1 与 `sourceSettings` 1 的 Lithe 宿主（Lithe Desktop 0.8.8 及以后版本）**。Lithe Desktop 0.8.7 继续使用 Java Support 4.1.0，更早版本继续使用 4.0.2。

---

## English

Adds multi-mirror automatic selection and failover for the managed JDK 25 download, significantly speeding up Java plugin installation in mainland China.

### New features

- **Managed JDK 25 mirror failover (`managedRuntimes` 1)**: switches the service JDK 25 for macOS, Linux and Windows x64 to Eclipse Temurin `25.0.5+8` with official Adoptium, NJU and Tsinghua TUNA mirrors. The host probes mirrors in parallel and automatically fails over on errors or low throughput while verifying the exact pinned SHA-256.

### Compatibility

- **Requires a Lithe host advertising `managedRuntimes` 1 and `sourceSettings` 1 (Lithe Desktop 0.8.8 or later)**. Lithe Desktop 0.8.7 keeps Java Support 4.1.0, and earlier versions keep 4.0.2.
