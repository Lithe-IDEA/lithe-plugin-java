# Java Support 4.3.0

## 中文

- 接口、抽象类、重写方法与实现类/子类之间新增双向跳转，支持 `Go to Implementation` 与 `Go to Super Declaration`（含未显式标注 `@Override` 的继承方法与泛型父类/接口声明）。
- 编辑器左侧行号栏新增 IntelliJ IDEA 风格语义导航图标（绿色 `I↓` / `I↑` 表示接口实现关系，蓝色 `O↓` / `O↑` 表示继承与重写关系），支持悬停查看目标并点击跳转；在不支持细分图标的旧版宿主上自动回退为通用导航图标。

### 兼容性

请使用支持 `toolDefinitions: 1`、`sourceSettings: 1`、`managedRuntimes: 1` 和 `ui: 0` 的 Lithe 桌面端；细分绿色 `I` / 蓝色 `O` 左侧行号栏图标与双向实现跳转需要 Lithe 桌面端 0.8.17 及以上版本。较早的宿主会自动回退显示通用导航图标，或继续使用兼容的插件版本。

---

## English

- Add bidirectional navigation between interfaces, superclasses, overridden methods, and their implementations/subclasses, supporting `Go to Implementation` and `Go to Super Declaration` (including generic supertypes and methods without `@Override`).
- Show IDEA-style gutter navigation icons (`I↓` / `I↑` in green for interface implementations, `O↓` / `O↑` in blue for inheritance overrides) with hover tooltips and one-click/multi-target navigation, falling back to generic navigation icons on older Lithe hosts.

### Compatibility

Use a Lithe desktop host that supports `toolDefinitions: 1`, `sourceSettings: 1`, `managedRuntimes: 1`, and `ui: 0`. Distinct green `I` / blue `O` gutter icons and bidirectional implementation navigation require Lithe Desktop 0.8.17 or later; earlier hosts automatically fall back to generic navigation icons or can keep compatible plugin versions.
