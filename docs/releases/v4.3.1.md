# Java Support 4.3.1

## 中文

- macOS 新增本机 JDT LS 自动发现（检查 `~/Library/Application Support/*/tools/jdtls`），并在“语言服务器”设置中新增“Java 环境”状态行与“检查”诊断弹窗，展示上次启动检查选用的服务与 JDK 路径，以及自动候选的来源和检查结果。
- 启动、调试与测试 Java 应用时默认启用 UTF-8 编码参数（`-Dfile.encoding=UTF-8`、`-Dsun.stdout.encoding=UTF-8`、`-Dsun.stderr.encoding=UTF-8`），并保留用户已显式设置的启动参数。

### 兼容性

请使用支持 `toolDefinitions: 1`、`sourceSettings: 1`、`managedRuntimes: 1` 和 `ui: 0` 的 Lithe 桌面端；细分绿色 `I` / 蓝色 `O` 左侧行号栏图标与双向实现跳转需要 Lithe 桌面端 0.8.17 及以上版本。较早的宿主会自动回退显示通用导航图标，或继续使用兼容的插件版本。

---

## English

- Discover local Eclipse JDT Language Server installations on macOS (`~/Library/Application Support/*/tools/jdtls`), and add a "Java environment" status row with a "Check" diagnostic dialog in Language Server settings to show the active language server and JDK paths and inspect candidate sources.
- Default to UTF-8 JVM encoding (`-Dfile.encoding=UTF-8`, `-Dsun.stdout.encoding=UTF-8`, `-Dsun.stderr.encoding=UTF-8`) when launching, debugging, or testing Java applications while preserving explicit user arguments.

### Compatibility

Use a Lithe desktop host that supports `toolDefinitions: 1`, `sourceSettings: 1`, `managedRuntimes: 1`, and `ui: 0`. Distinct green `I` / blue `O` gutter icons and bidirectional implementation navigation require Lithe Desktop 0.8.17 or later; earlier hosts automatically fall back to generic navigation icons or can keep compatible plugin versions.
