# Java 4.0.0

## 中文

“Java 库”页升级为“Java 项目结构”，对标 IntelliJ IDEA 的“项目结构 → 模块”：左侧是模块列表，右侧按“源 / 路径 / 依赖”标签页逐个配置（[1lck/Lithe-IDEA#2086](https://github.com/1lck/Lithe-IDEA/issues/2086)）。

### 新功能

- **Eclipse 工程按模块编辑**：源文件夹（可标为测试）、输出文件夹、JRE（工作区默认或 JavaSE 执行环境）和依赖列表，保存时写回模块的 `.classpath`。
- **依赖列表**：可添加 JAR/ZIP、类文件夹、库容器（JUnit 4/5、Web App Libraries、EAR Libraries 及工作区已用到的用户库和 Server Runtime）和其他模块；可调整顺序，每项可标“导出”“仅测试”。
- **保留原文件内容**：源码附件、Javadoc 位置、访问规则、注释和页面不显示的条目都保持不变。
- **Maven、Gradle 模块只读显示** JDT 解析出的完整类路径（含测试依赖），提示在构建文件里修改。
- 设置动作“读取本地 JAR 依赖”改名为“读取项目结构”；没有 `.classpath` 的普通文件夹仍在“引用的库”分组里编辑。

详见 `docs/module-structure.md`。

### 兼容性

**需要声明 `sourceSettings` 1 的 Lithe 宿主**（[1lck/Lithe-IDEA#2087](https://github.com/1lck/Lithe-IDEA/pull/2087)），因此是主版本升级。商店会让不支持它的宿主继续安装 3.0.1。已在 JDT LS 1.61.0 上验证。

## English

The **Java Libraries** page becomes **Java Project Structure**, after IntelliJ IDEA's Project Structure → Modules: a module list on the left and Sources / Paths / Dependencies tabs for the selected module ([1lck/Lithe-IDEA#2086](https://github.com/1lck/Lithe-IDEA/issues/2086)).

### New

- **Eclipse projects are edited module by module**: source folders (optionally marked as test), output folder, JRE (workspace default or a JavaSE execution environment) and dependencies, saved to the module's `.classpath`.
- **Dependency list**: add JARs/ZIPs, class folders, library containers (JUnit 4/5, Web App Libraries, EAR Libraries, and the user libraries and Server Runtimes the workspace already uses) and other modules; reorder them, and mark each as Export or Test only.
- **The rest of the file is kept**: source attachments, Javadoc locations, access rules, comments and entries the page does not show stay as they are.
- **Maven and Gradle modules are shown read-only** with the classpath JDT resolved, test dependencies included; change them in the build file.
- The **Read local JAR dependencies** action is now **Read project structure**; plain folders without `.classpath` are still edited in the **Referenced libraries** group.

See `docs/module-structure.md`.

### Compatibility

**Requires a Lithe host advertising `sourceSettings` 1** ([1lck/Lithe-IDEA#2087](https://github.com/1lck/Lithe-IDEA/pull/2087)), hence the major version. The store keeps offering 3.0.1 to hosts without it. Verified on JDT LS 1.61.0.
