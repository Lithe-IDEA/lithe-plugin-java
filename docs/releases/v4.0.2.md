# Java 4.0.2

## 中文

为传统 JavaEE 项目补上两项基础能力：JSP 文件有了语法着色，Eclipse Web 项目可以在项目结构里改 Web 模块版本。

### 新功能

- **JSP 语法着色**：`.jsp`、`.jspf`、`.tag`、`.tagf` 文件按 HTML 着色，并识别 JSP 注释、指令、脚本片段、JSP/JSTL 标签和 EL 表达式（`${...}`、`#{...}`）；`<script>`、`<style>` 里的 JavaScript 和 CSS 照常着色。这是语法着色，不含 JSP 的补全、诊断和跳转（[#30](https://github.com/Lithe-IDEA/lithe-plugin-java/pull/30)）。
- **编辑 Eclipse Web 模块版本**：已有 `.classpath` 的 Eclipse Dynamic Web Project，在「Java 项目结构」里多一个「Web Facets」页，可以选择 Dynamic Web Module（`jst.web`）的版本。打开页面不写文件；保存时只改这个版本，其他 Facet、注释和 `.classpath` 不动。Facet 文件格式不合规时只跳过这一项，项目结构其他内容照常显示（[#31](https://github.com/Lithe-IDEA/lithe-plugin-java/pull/31)）。

### 兼容性

与 4.0.0 相同，**需要声明 `sourceSettings` 1 的 Lithe 宿主**。JSP 中嵌在 HTML 属性值、脚本和样式里的 EL 需要 0.8.4 及以后的桌面端；更早的版本只识别正文层级的 JSP。在 Tomcat 上运行和调试 Web 项目由 [Tomcat 插件](https://github.com/Lithe-IDEA/lithe-plugin-tomcat)提供。

## English

Two basics for classic Java EE projects: JSP files are highlighted, and Eclipse Web projects can change their Web module version in Project Structure.

### New features

- **JSP highlighting**: `.jsp`, `.jspf`, `.tag` and `.tagf` files are highlighted as HTML, with JSP comments, directives, scriptlets, JSP/JSTL tags and EL expressions (`${...}`, `#{...}`); JavaScript and CSS inside `<script>` and `<style>` stay highlighted. This is highlighting only, without JSP completion, diagnostics or navigation ([#30](https://github.com/Lithe-IDEA/lithe-plugin-java/pull/30)).
- **Edit the Eclipse Web module version**: an Eclipse Dynamic Web Project that has a `.classpath` gets a "Web Facets" page in Java Project Structure for choosing the Dynamic Web Module (`jst.web`) version. Opening the page writes nothing; saving changes only that version and leaves other facets, comments and `.classpath` untouched. A facet file Lithe cannot safely read is skipped and the rest of Project Structure still shows ([#31](https://github.com/Lithe-IDEA/lithe-plugin-java/pull/31)).

### Compatibility

Same as 4.0.0: **requires a Lithe host advertising `sourceSettings` 1**. EL inside HTML attribute values, scripts and styles needs desktop 0.8.4 or later; earlier versions recognize JSP at the top level only. Running and debugging Web projects on Tomcat comes from the [Tomcat plugin](https://github.com/Lithe-IDEA/lithe-plugin-tomcat).
