# Java Support 4.2.2

## 中文

- 普通 Java 和传统 Java EE 项目可以按模块标记源码、测试、资源和排除目录，并管理输出路径、JAR、库目录和类目录。
- 打开 IntelliJ IDEA 项目时，可以查看模块的目录、SDK、编译输出和依赖，并跳转到已加载的类目录依赖。
- 工具链设置分开显示项目 JDK 和语言服务 JDK，Java 语言与编译器设置支持关键词搜索和实时预览。

### 兼容性

请使用支持 `toolDefinitions: 1`、`sourceSettings: 1`、`managedRuntimes: 1` 和 `ui: 0` 的 Lithe 桌面端，例如 0.8.12。较早的宿主可继续使用兼容的插件版本。

---

## English

- Mark source, test, resource, and excluded folders by module in plain Java and legacy Java EE projects, and manage output paths, JARs, library folders, and class directories.
- View module roots, SDKs, compiler output, and dependencies in IntelliJ IDEA projects, and navigate to classes from loaded class directories.
- Toolchain settings list the project JDK and language server JDK separately. Search Java language and compiler settings by keyword and preview changes as you edit.

### Compatibility

Use a Lithe desktop host that supports `toolDefinitions: 1`, `sourceSettings: 1`, `managedRuntimes: 1`, and `ui: 0`, such as 0.8.12. Earlier hosts can keep their compatible plugin version.
