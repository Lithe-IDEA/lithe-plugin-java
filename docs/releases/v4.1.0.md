# Java 4.1.0

## 中文

安装 Java 插件时自动准备并复用专用的完整 JDK 25 与 Eclipse JDT Language Server 1.61.0，不再要求用户提前手工下载语言服务运行环境，同时保持项目自身 JDK 独立选择。

### 新功能

- **自动准备与复用 Java 语言服务运行环境（`managedRuntimes`）**：安装插件前先检查显式配置、已有缓存和本机兼容安装，仅下载缺失或不兼容的官方归档（Microsoft Build of OpenJDK 25.0.5.0.2 与 Eclipse JDT LS 1.61.0）并做完整 SHA-256 校验。运行环境保存在插件包之外的独立状态目录，后续插件更新复用同一份缓存；该 JDK 仅用于运行 JDT LS（`jdtls-runtime`），不影响项目自身的 `java` 工具链、Maven 或 Gradle JDK（[#34](https://github.com/Lithe-IDEA/lithe-plugin-java/pull/34)）。

### 兼容性

- **需要声明 `managedRuntimes` 0 与 `sourceSettings` 1 的 Lithe 宿主（Lithe Desktop 0.8.7 及以后版本）**。更早的桌面端版本请继续使用 Java Support 4.0.2。

---

## English

Automatically prepares and reuses a private full JDK 25 and Eclipse JDT Language Server 1.61.0 when installing the Java plugin, without affecting the project's own JDK selection.

### New features

- **Managed Java language server runtimes (`managedRuntimes`)**: checks explicit settings, existing caches and compatible local installations before installing, downloading only missing or incompatible official archives (Microsoft Build of OpenJDK 25.0.5.0.2 and Eclipse JDT LS 1.61.0) with full SHA-256 verification. Runtimes are stored outside the plugin package and reused across plugin updates; this JDK is bound only to `jdtls-runtime` and leaves the project's `java` toolchain, Maven and Gradle JDKs untouched ([#34](https://github.com/Lithe-IDEA/lithe-plugin-java/pull/34)).

### Compatibility

- **Requires a Lithe host advertising `managedRuntimes` 0 and `sourceSettings` 1 (Lithe Desktop 0.8.7 or later)**. Earlier desktop versions continue to use Java Support 4.0.2.
