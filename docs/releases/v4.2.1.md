# Java 4.2.1

## 中文

修复 JDT LS 启动参数传递与工作区构建顺序问题，并补全 JUnit 6 测试识别，解决编辑区内点击运行 Java 测试用例无响应或无法启动的问题。

### 修复

- **完整保留测试运行参数（[#41](https://github.com/Lithe-IDEA/lithe-plugin-java/pull/41)）**：修正测试启动参数解析时丢失字符串参数或误传整数字段的缺陷，完整保留 JDT LS 返回的运行器 `args`、`vmArgs` 与 classpath，并在触发启动前先执行工作区编译，避免类输出缺失导致测试无法运行。
- **支持 JUnit 6 测试运行**：补充对 JDT LS `JUNIT6` / `junit6` 测试种类的识别，完整解析并执行 JUnit 6 单元测试。

### 兼容性

与 4.2.0 相同，**需要声明 `managedRuntimes` 1 与 `sourceSettings` 1 的 Lithe 宿主（Lithe Desktop 0.8.8 及以后版本）**。Lithe Desktop 0.8.7 继续使用 Java Support 4.1.0，更早版本继续使用 4.0.2。

---

## English

Fixes Java test execution launch argument handling, pre-test workspace building, and JUnit 6 recognition so running Java unit tests from the editor works reliably.

### Fixes

- **Preserve typed test runner launch arguments ([#41](https://github.com/Lithe-IDEA/lithe-plugin-java/pull/41))**: preserves all string arguments and JVM options returned by Eclipse JDT LS when assembling test runs and triggers a workspace build before launching tests so compiled class outputs are up to date.
- **JUnit 6 test execution support**: recognizes JDT LS `JUNIT6` / `junit6` test kinds so JUnit 6 tests resolve and execute cleanly.

### Compatibility

Same as 4.2.0: **requires a Lithe host advertising `managedRuntimes` 1 and `sourceSettings` 1 (Lithe Desktop 0.8.8 or later)**. Lithe Desktop 0.8.7 keeps Java Support 4.1.0, and earlier versions keep 4.0.2.
