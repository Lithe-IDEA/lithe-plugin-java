## 中文

Java Support 1.2.0 为配套 Viva 预览版新增无源码依赖类导航。本版本是预发布，插件 ZIP 不带发布者签名。

### 下载与安装

选择 macOS Apple Silicon（`darwin-arm64`）、macOS Intel（`darwin-x64`）或 Windows x64（`windows-x64`）ZIP，在 Viva 插件设置中从文件安装。Maven/Gradle 插件沿用 Maven 0.0.1、Gradle 1.0.0。

原有项目工作流仍需包含 [Lithe #1884](https://github.com/1lck/Lithe-IDEA/pull/1884) 的兼容 Viva 与 Core #29；新增的虚拟类间导航还需 [Lithe #1906](https://github.com/1lck/Lithe-IDEA/pull/1906) 的虚拟文档语言/URI 与过期导航取消修复。契约、API、能力版本仍为 0，没有增加权限或外部工具要求。

### 更新

- 可只读打开依赖 JAR 中没有源码的类，跳到类型和方法定义，并从类视图继续跳转其他类。
- 修复缺少内部类文件时，现有外部类也无法打开的问题；缺失类本身无法恢复。
- 内容请求有超时、取消与大小限制，插件不新增源码缓存或后台轮询，安装目录保持只读。

### 兼容性与已知限制

- 缺失的第三方依赖可能使部分成员无法解析；不能把两个独立 class 文件视为完整可编译工程。
- JSP 当前仍按 HTML 打开，没有 JSP 内 Java 补全、导航或源码断点支持。
- 构建期修改的 JDT core JAR 已移除失效的 Eclipse JAR 签名，随包附带修改的 EPL-2.0 源码和补丁哈希；原生 JVM 签名不变。
- 本版不宣称整体内存或响应速度下降。原生窗口、完整日志/取消分支、JUnit/TestNG 与 Spring/MyBatis 等范围仍见 README；Java 5/7 源码、长 module-path、JavaCC、多版本 JAR 和部分旧泛型限制继续保留。

[对比 1.1.3 与 1.2.0](https://github.com/Lithe-IDEA/lithe-plugin-java/compare/v1.1.3...v1.2.0)

## English

Java Support 1.2.0 adds navigation into binary dependencies for the matching Viva preview. This prerelease uses unsigned plugin ZIPs.

### Download and installation

Install the macOS Apple Silicon (`darwin-arm64`), macOS Intel (`darwin-x64`), or Windows x64 (`windows-x64`) ZIP from a file in Viva's plugin settings. Continue using Maven 0.0.1 and Gradle 1.0.0.

Existing project workflows still require compatible Viva including [Lithe #1884](https://github.com/1lck/Lithe-IDEA/pull/1884) and Core #29. Further navigation from virtual class views requires [Lithe #1906](https://github.com/1lck/Lithe-IDEA/pull/1906), which fixes virtual-document language/URI synchronization and obsolete-navigation cancellation. Contract, API and capability versions remain 0, without additional permissions or external tools.

### Changes

- Open dependency classes without attached sources read-only, navigate to type and method definitions, and continue to other classes.
- Prevent missing inner-class files from making the available outer class unreadable; missing class bodies cannot be recovered.
- Content requests are bounded and cancellable, without a new plugin source cache or background polling; installed packages remain read-only.

### Compatibility and known limitations

- Missing third-party dependencies can leave some members unresolved; two standalone class files do not form a complete buildable project.
- JSP still opens as HTML, without Java completion, navigation or JSP-source breakpoints.
- The build-modified JDT core JAR removes its invalid Eclipse JAR signature and includes modified EPL-2.0 source and patch hashes; native JVM signatures are unchanged.
- This release claims no overall memory or responsiveness improvement. README retains native-window, logging/cancellation, JUnit/TestNG and Spring/MyBatis acceptance limits, plus Java 5/7, long module-path, JavaCC, multi-release JAR and older generic-code limitations.
