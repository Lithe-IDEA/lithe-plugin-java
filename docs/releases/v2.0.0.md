# Java 2.0.0

## 中文

- 新增真实项目编译设置、项目默认目标与按模块字节码覆盖，保存后重新读取生效配置。
- 新增本地 JAR 引用入口，保留无关的项目配置与注释。

### 兼容性

此主版本新增 `sourceSettings: 0` 宿主要求；旧宿主无法安装，应继续使用上一兼容版本或先升级桌面端。读取项目工具可能执行项目代码及下载依赖；仅明确保存才修改列出的配置文件。详见 [编译设置说明](../native-settings.md)。

---

## English

- Add native compiler settings with project defaults, per-module bytecode overrides and effective-value readback.
- Add local JAR dependencies while preserving unrelated project configuration and comments.

### Compatibility

This major release requires `sourceSettings: 0`. Upgrade the desktop host first, or keep the previous compatible plugin version. Reading project tools may execute project code and download dependencies. Only explicit Save changes the displayed native sources.
